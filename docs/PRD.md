# 课堂评分投票系统 PRD

## 1. 文档信息

- 产品名称：课堂评分投票系统
- 版本：V1.0
- 目标用户：授课老师（管理员）、参与评分的学员（投票人）

## 2. 背景与目标

项目实战展示环节需要全员对同一份**通用问卷**打分。老师在后台维护评分题、组成问卷并开放链接；学员打开链接填写后提交；同一 IP 对同一问卷只能提交一次；老师在后台查看人数与各题均分等基础统计。

成功标准：局域网内可演示完整链路——登录 → 建题 → 组卷 → 投票 → 防重复 → 看统计。

## 3. 角色与权限

| 角色 | 能力 |
| --- | --- |
| 管理员 | 账号密码登录/登出；题目 CRUD；问卷 CRUD（选题、排序、开放/关闭、问卷地址）；查看某问卷统计。无多角色、无细粒度权限。 |
| 投票人 | 无需注册。打开问卷链接后对问卷内每道评分题打分并提交（可填写姓名等展示信息）。同一 IP 同一问卷不可重复提交。不能访问后台。 |

## 4. 用户故事

- 作为管理员，我希望用账号密码登录后台，以便只有老师能改题和看结果。
- 作为管理员，我希望先维护评分题（如 1～10 分），再挑选题目组成问卷，以便复用题库。
- 作为管理员，我希望得到可分享的问卷地址，并能开放或关闭投票。
- 作为投票人，我希望打开链接后对每题打分提交，操作尽量简单。
- 作为系统，按 IP 计算，同一个 IP 同一个问卷不能重复提交，防止刷分。
- 作为管理员，我希望看到该问卷的提交人数、各题平均分（及可选总分/均分汇总），以便课堂点评。

## 5. 功能需求

### 5.1 后台登录

- 管理员使用用户名 + 密码登录；登录态失效后需重新登录才能进后台。
- 初始管理员账号可通过环境变量或初始化脚本配置；密码不得明文写入代码仓库。
- 支持登出。

### 5.2 题库

- 题目类型：本节只做**评分题**（整数分，默认 1～10，可配置上下限）。
- 字段至少包含：题目标题、可选说明、分值下限、分值上限。
- 支持新增、编辑、删除、列表查看。

### 5.3 问卷

- 创建问卷：标题、可选说明；从题库多选题目并设定展示顺序。
- 每份问卷生成可访问的前台地址（URL），用于分享给投票人。
- 可开放 / 关闭投票；关闭后前台不可再提交。
- 支持查看问卷列表、编辑（至少能改标题说明、题目组成、开关状态）。

### 5.4 前台投票

- 通过问卷地址（URL）打开问卷。
- 展示问卷标题、说明及全部评分题；投票人为每题选择分值并提交（姓名等为可选展示字段）。
- 按客户端 IP + 问卷 ID 唯一约束；同一 IP 对同一问卷重复提交须被拒绝并给出明确提示。
- 问卷不存在、已关闭或未开放时，前台给出可读提示。

### 5.5 统计

- 后台按问卷查看：提交总人数；每道题的平均分；可选展示有效答卷列表（IP / 可选姓名 + 提交时间，不含改分）。
- 统计数据与数据库中已提交答卷一致。
